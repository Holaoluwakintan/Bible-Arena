# Bible Arena

Bible Arena is a mobile-first competitive Bible knowledge game.

> **Know the Word. Challenge the World.**

## Repository status

This repository currently contains the product and technical specifications for Bible Arena. The application source code has not yet been added.

The documented roadmap describes product work through Phase 23, but those phases are specifications and handoff records in this repository until the corresponding implementation is committed and verified here.
