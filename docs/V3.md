# Bible Arena v3

v3 is a new, fast web game. It is served by the same Express server at `/`, `/d/:code` and `/v3/*`. The classic Expo app (v2) keeps its own routes: `/play`, `/quiz`, `/room`, `/ai-battle`, `/friends`, `/leaderboards`, `/profile` and so on.

## What's in it
- **Modes:** Fill in the Gap, Who Am I (4 clues), Bible or Myth, Arena Quiz, Mixed, Sudden Death and the Daily Challenge.
- **Levels:** Believer (the classic v2 questions), Scholar and Theologian.
- **Progress:** ranks from Seeker to Apostle, streaks, 24 achievements, and sound and vibration toggles.
- **Pastor duels:** `POST /api/v3/duels` creates a set and a link at `/d/CODE`, with a WhatsApp/OG preview.
  - The challenger plays the same questions. Both players see each other's progress live (polling).
  - The result screen compares the two players question by question, then offers a rematch.
- **Leaderboards:** weekly, all-time, Pastors' League (grouped by church), rivals (head-to-head), and today's daily.

## Data
- **Durable data** lives in Postgres: Supabase, schema `bible_arena`, role `bible_arena_app` (least privilege), env `BA_DATABASE_URL`.
- **Legacy SQLite** (users, friends, rooms, v2 challenges) is restored from `bible_arena.sqlite_snapshots` at boot. It is snapshotted back every 15 s when it changes, and again on shutdown (`server/persist.ts`). Render's disk wipes no longer reset accounts.
- **Question bank:** `web-v3/bank.json` is built from `files/bible-arena/v3-content` (KJV-checked). The server re-scores every answer against it.

## Test
`node scripts/v3-smoke.mjs <base-url>` runs the two-player duel, round and leaderboard checks end to end.
