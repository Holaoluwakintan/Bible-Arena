# Bible Arena

Bible Arena is a mobile-first competitive Bible knowledge game.

> **Know the Word. Challenge the World.**

## Project status

The project is currently completing **Phase 0 — Product Foundation**. The product scope, core gameplay loop, MVP, screen map, initial rules, content verification requirements, data model, and Phase 1 handoff are documented in:

- [Bible Arena Product Specification](docs/PRODUCT_SPEC.md)

## Build roadmap

1. Product Foundation
2. Technical and Design Foundation
3. Database and Question System
4. Reusable Game Engine
5. Bible Quiz
6. XP, Levels, and Streaks
7. Additional game modes and social features

Implementation should proceed one phase at a time using **Audit → Plan → Implement → Test → Fix → Polish → Report**.
